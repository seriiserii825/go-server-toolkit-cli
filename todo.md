# Практика № 07 — Server Toolkit CLI

Предлагаю сделать CLI-приложение Server Toolkit на Go — утилиту для
управления серверами через терминал.

Это будет практика на `func`, параметры, `return`, `package`, `import`,
экспорт функций и работу с несколькими файлами. Без готового решения,
чтобы ты написал всё самостоятельно.

**Средний уровень** · Мини-проект · 3 пакета · 6 заданий

## Структура проекта

```
07-server-toolkit/
├── go.mod
├── main.go
├── server/
│   ├── server.go
│   └── status.go
└── utils/
    ├── format.go
    └── validation.go
```

## Задания

- [ ] **1. Создать пакет `server`**
  В `server/server.go` создай функции `GetServerName() string`,
  `GetTotalStorage() float64`, `GetUsedStorage() float64`. Они должны
  возвращать имя сервера, 500 и 375.5. Добавь приватную функцию
  `getServerID() int` и попробуй вызвать её из `main.go`.

- [ ] **2. Расчёт свободного места**
  В `server/status.go` создай `GetFreeStorage(total, used float64)
  float64` и `GetDiskUsage(total, used float64) float64`. Вторая
  функция должна возвращать процент использования. Обработай случай
  `total <= 0`.

- [ ] **3. Проверка состояния**
  В `utils/validation.go` реализуй `IsStorageCritical(usage float64)
  bool`. Если использование диска превышает 70%, возвращай `true`.
  Также создай `GetStorageStatus(usage float64) string`: `OK`,
  `WARNING` или `CRITICAL`. Пороги: до 70% включительно — `OK`, выше
  70% до 90% включительно — `WARNING`, выше 90% — `CRITICAL`.

- [ ] **4. Форматирование отчёта**
  В `utils/format.go` создай `FormatStorage(value float64) string`,
  которая превращает `375.5` в `375.50 GB`. Используй
  `fmt.Sprintf()`. Затем создай `FormatPercentage(value float64)
  string` для процентов.

- [ ] **5. Собрать всё в main.go**
  Импортируй `server` и `utils`. Получи данные о сервере, вычисли
  свободное место и процент использования, проверь состояние и выведи
  полный отчёт. Не дублируй вычисления в `main.go`.

- [ ] **6. Бонус: несколько результатов**
  Создай в `server/status.go` функцию `AnalyzeStorage(total, used
  float64) (float64, float64, error)`. Она должна возвращать свободное
  место, процент использования и ошибку при некорректных данных
  (`total <= 0`, `used < 0` или `used > total`). В `main.go` обработай
  `err`.

**Выполнено: 0 из 6**

## Дополнительные проверки

Протестируй программу с тремя наборами значений:

| Total | Used  | Ожидаемый статус |
|-------|-------|-------------------|
| 500   | 250   | OK                |
| 500   | 375.5 | WARNING           |
| 500   | 475   | CRITICAL          |

**Главное ограничение:** в `main.go` должна остаться только логика
вызова функций и вывода результата. Все вычисления и проверки
выполняй в отдельных пакетах.

Когда напишешь программу, пришли свой код — проверю архитектуру
пакетов, правильность экспорта функций, обработку ошибок и подскажу,
что можно улучшить без переписывания всего за тебя.
